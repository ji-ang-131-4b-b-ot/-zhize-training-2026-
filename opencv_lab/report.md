# B.1 OpenCV 基础图像处理与人脸模糊

一、实验目的
掌握图像的矩阵组织结构、BGR 通道顺序、像素数值范围、基于数组切片的感兴趣区域截取与覆盖操作，以及高斯
滤波核尺寸对平滑效果的影响。在本节中Open CV可以在计算机中调整亮度、对比度、颜色，进行裁剪和模糊处理。
二、实验环境
- 操作系统：Windows
- 编程语言：Python
- 开发工具：Visual Studio Code
- 图像处理库：OpenCV

三、实验内容与结果
本次实验使用 Python 和 OpenCV 库对图像进行基础处理，主要完成了图片读取与显示、图像裁剪、亮度与对比度调整、高斯模糊、人脸检测以及人脸局部模糊等操作。我采取的学习方法是先学理论再实践。

读取图片：使用 `cv2.imread()` 读取本地图片，并通过 `cv2.imshow()` 显示原始图像。通过 `img.shape` 获取图片的尺寸信息，了解了彩色图像在内存中以多维数组形式存储，其三个维度分别表示高度、宽度和颜色通道数。

图像裁剪：利用 NumPy 数组切片实现图像裁剪，通过 `img[y:y+h, x:x+w]` 截取指定区域，并将裁剪结果保存到指定文件夹。通过调整切片坐标，观察了不同区域的裁剪效果，掌握了图像 ROI（感兴趣区域）的基本操作方法。

亮度和对比度：使用 `cv2.convertScaleAbs()` 对图像进行亮度和对比度调整，通过改变参数 alpha 和 beta，设置了三组来观察不同参数对图像显示效果的影响，并保存处理后的图片。

全局模糊化：在图像平滑处理部分，使用 `cv2.GaussianBlur()` 对原始图像进行高斯模糊，分别设置不同的卷积核尺寸，对比了不同模糊程度下的图像效果，理解了高斯核尺寸对图像平滑程度的影响。

人脸检测：在人脸检测部分，首先使用 Haar Cascade 分类器加载预训练的人脸检测模型，再将彩色图像转换为灰度图，调用 `detectMultiScale()` 函数检测人脸，并使用 `cv2.rectangle()` 在检测到的人脸位置绘制矩形框。运行结果正常，成功检测出一张人脸。

人脸模糊：完成了人脸局部模糊处理。根据人脸检测得到的坐标，使用数组切片截取人脸区域，再通过高斯模糊处理该区域，并将处理后的像素重新覆盖到原图对应位置，最终实现了人脸模糊而背景基本保持清晰的效果。

通过本次实验，完成了 OpenCV 基础图像处理与人脸模糊的主要操作，初步掌握了图像矩阵结构、BGR 颜色通道、ROI 区域截取、高斯滤波以及人脸检测和局部像素替换等基本方法。
四、思考题

1. OpenCV 读取的彩色图像在内存中本质上是什么数据结构？shape 的三个维度分别代表什么？

OpenCV 读取的彩色图像在内存中本质上是一个 NumPy 多维数组（ndarray）。 默认使用 BGR 颜色顺序，分别表示蓝色（Blue）、绿色（Green）和红色（Red）。shape的三个维度分别是图像的高度，图像的宽度，图像的颜色通道数。

 2. 图像裁剪与局部区域模糊在底层数组层面对应什么操作？

图像裁剪和局部区域模糊本质上都是对 NumPy 数组进行索引、切片和赋值操作。
截取部分：使用 img[y:y+h, x:x+w] 对图像数组进行切片，提取指定坐标范围内的像素，得到感兴趣区域（ROI）。
模糊部分：使用 cv2.GaussianBlur() 对截取的区域进行高斯模糊处理，生成新的模糊图像数组。
人脸模糊：通过 result[y:y+h, x:x+w] = blurred_face 将模糊处理后的像素值重新赋给原图对应位置，从而实现只模糊指定区域、保留其他区域不变的效果。
因此，图像裁剪主要对应数组切片操作，而局部模糊则结合了数组切片、图像处理和数组赋值操作。
